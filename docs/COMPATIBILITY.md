# Python compatibility and current evidence

`pyproject.toml` declares Python >=3.11; this is a packaging requirement, not verification on every OS/patch release. Previous 3.11/3.12 dev1 release CI at 41262690722 passes 56/56 public tests in normal and optimized modes, 3.12 wheel and sdist install, and the existing demos. **Those receipts are for dev1**. The new dev2 FastAPI integration and source-only robotics reproduction require fresh CI; a separate public-export gate will be the release's authority. Our optional FastAPI example also needs `fastapi` and `httpx`. Physical robot support and official MCP SDK compatibility are not verified; no real external-effect finality is claimed.
