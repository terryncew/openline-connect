# Contributing to this developer preview

Use the public source checkout with Python >=3.11. Run `python -m unittest discover -s tests -q` and `python -O -m unittest discover -s tests -q`, the installed CLI demos, both native conformance targets, FastAPI example (optional dependencies), simulated robotics A/B/V comparator and negative control. Include exact interpreter/platform, expected/actual status, and any SQLite/journal receipt mismatch. Do not attach real credentials, logs with secrets, customer data or physical controller commands. Source and API stability are preview-quality; contributions and support turnaround are **not promised**. No paid support, production SLA, or remotely operated support bot is claimed.
